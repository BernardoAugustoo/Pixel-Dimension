# 🎮 Projeto — Pixel Dimension
> Um jogo de plataforma 2D com combate, ondas de inimigos e fases inspiradas em diferentes universos dos videogames.

## 📖 Sobre o projeto

Este projeto está sendo desenvolvido como parte do **Trabalho Prático 2 — Aplicação Web**.

A proposta é criar um jogo de plataforma 2D com visão lateral, no qual o jogador deverá enfrentar inimigos em ondas progressivas e avançar por quatro fases diferentes, cada uma com seu próprio cenário, personagem e desafios.

## 🕹️ Como funciona o jogo

- **4 fases:** cada uma com cenário, personagem e inimigos próprios.
- **Ondas de inimigos:** o jogador enfrentará três ondas por fase, com quantidade progressiva de adversários.
- **Sistema de combate:** movimentação lateral, saltos e ataques com arma corpo a corpo.
- **Sistema de pontuação:** acompanhamento do desempenho durante as partidas.
- **Vitória e derrota:** telas específicas para conclusão de fases e tentativas novamente.

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.

> Durante o desenvolvimento, recomendamos utilizar o Live Server para facilitar os testes e a atualização da aplicação.
